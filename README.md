# Комната ожидания совещания

[Открыть интерактивный прототип](https://doorotar9-png.github.io/meeting-waiting-room-preview/).

Отдельный проект комнаты ожидания и входа в совещание. Доступны режимы сотрудника/гостя, составы2/5/16, описание и повестка, файлы, три шага сценария, фон и отступы на сцене. При перезагрузке настройки возвращаются к начальным.

Здесь находится только готовая статическая сборка. Люди, данные встречи, содержимое файлов и медиа демонстрационные; серверные операции и видеосвязь симулируются локально. Для просмотра ничего устанавливать не требуется. Общий прототип видеозвонка опубликован отдельно.
